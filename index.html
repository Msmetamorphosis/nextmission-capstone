Project Overview
AI-Driven Veteran Transition Support Platform
NextMission Navigator is a full-stack, production-grade web application assisting U.S. military veterans transitioning to civilian life. Using the Anthropic Claude API with retrieval-augmented generation, it produces personalized, schema-validated action plans from natural language goals — grounded in a curated regional resource catalog covering career, education, housing, healthcare, finance, and community support. A dual-AI interface combines a text chatbot with an ElevenLabs voice agent for 24/7 accessible guidance. This capstone is a complete custom rebuild (v3) replacing a prior low-code prototype, deployed live at VetNavi.AI.
